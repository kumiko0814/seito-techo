# 生徒手帳（放課後最強フェス 公式アプリ・Web版）

放課後最強フェス（2026年11月・飯田橋）の専用アプリ「生徒手帳」。
ダンガンロンパの電子生徒手帳の構造（学生証／校則／レポートカード）を参考に、フェス世界観で構築。

- 本番: https://kumiko0814.github.io/seito-techo/

## 機能（v2）
| タブ | 内容 |
|---|---|
| 学生証 | 写真登録（端末内保存）・無敵タイプ/クラス/部活/出席番号・最強認定スタンプ |
| しんだん | 無敵タイプ診断（12問4択・4タイプ→クラス/部活決定） |
| プロフ帳 | ラヴ上等風3セクション（My Profile/Personality/放課後Talk）＋デコエディタ（背景6種・SVGぷっくりシール16種・ドラッグ/サイズ/回転）＋QR/リンク交換 |
| ともだち | 交換で集めたプロフ帳コレクション（端末内保存） |
| こうそく | 逆・校則 九ヶ条 |

## 仕組み
- 診断保存: Supabase `promo_tasks` 相乗り run_id=`muteki-<ch>`
- プロフ帳共有: `promo_tasks` 相乗り run_id=`profcho`・task_key=`p_xxx` → `?p=p_xxx` で閲覧
- 不具合報告: `ailab_notes` 相乗り（member_id=`bug_seito-techo`・毎時パトロール対象）
- QRコード: cdnjs qrcodejs（読込失敗時はリンクコピーにフォールバック）
- `?ch=xxx` チャネル分離 ／ `?demo=1` 保存なし ／ `?debug=1` 画面内ログ ／ `?auto=1` 診断オートラン ／ `?tab=pgProf` 等でタブ直行
- デモ共有プロフ: `?p=p_test0831`
