# 生徒手帳（放課後最強フェス 公式アプリ・Web版）

放課後最強フェス（2026年11月・飯田橋）の専用アプリ「生徒手帳」。
第一機能＝**無敵タイプ診断**（12問・4タイプ・クラス分け＆部活推奨つき）。

- 診断: https://kumiko0814.github.io/seito-techo/

## 仕組み
- 12問・4択（各選択肢が1タイプに+1点）。最高点で判定（同点は併記）
- 4タイプ: 応援団長(主導)／ムードメーカー(促進)／交換日記の番人(支持)／学級新聞 編集長(分析) — ソーシャルスタイル理論ベース（seikaku-shindanのノウハウ流用）
- 結果にフェス当日の「クラス（1〜4組）」「おすすめ部活」を表示 → 当日のクラス分けに接続
- 結果保存: Supabase `promo_tasks` 相乗り（run_id=`muteki-<ch>`、SQL作業ゼロ）
- 不具合報告: `ailab_notes` 相乗り（member_id=`bug_seito-techo`）
- `?ch=xxx` チャネル分離 ／ `?demo=1` 保存なし ／ `?debug=1` 画面内ログ ／ `?auto=1` 動作確認オートラン
